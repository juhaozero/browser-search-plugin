# 搜索会话：判定、高亮、列模式、ingest 测试全绿

## What to build

让搜索会话成为可单独验证的竖切：给定页面文档、当前地址和偏好，就能判定是不是桌面版网页搜索、把查询拆成高亮段、推导下一页地址，并在文档上完成高亮、列模式和后续页接入。

偏好形状为：列模式 `original` | `single` | `single-center` | `double`，高亮与自动翻页为布尔值。默认不在这一刀里做弹窗，但会话必须能按传入偏好工作。

这一刀只覆盖领域行为，不接浏览器、不发网络请求。下一页用注入的文档交给会话接入。现有测试草稿是行为契约，先让它们通过，并补上「从其他列模式切回原始模式时，本页原有结果条目回到打开时的位置，已接上的结果仍留在列表末尾」。

## Acceptance criteria

- [x] 桌面版百度 `www.baidu.com` 网页搜索、谷歌 `www.google.com` 与带国家或地区后缀的 `/search` 网页搜索判定为真
- [x] 搜索首页、手机版、图片/资讯等垂类判定为假，且这些地址推不出下一页
- [x] 查询按空格和标点拆成高亮段；没有空格的连续中文整段不拆
- [x] 高亮只出现在结果条目的标题和摘要上；搜索框、相关搜索、广告上没有高亮
- [x] 非原始列模式只搬走结果条目，并标出当前列模式；页码、相关搜索、广告留在原地
- [x] 原始模式不搬走结果条目；从单列、单列居中或双列切回时，本页原有结果条目回到原位，已接入的后续结果仍在列表末尾
- [x] 接入下一页时跳过已有链接；没有新结果条目则停止；从当前页起最多再接 10 页
- [x] 接入的新结果条目沿用当前列模式；高亮开着时新结果条目的标题和摘要也被标出
- [x] 页码文案在接入后仍然留在页面上
- [x] 上述行为由搜索会话测试覆盖，测试通过
