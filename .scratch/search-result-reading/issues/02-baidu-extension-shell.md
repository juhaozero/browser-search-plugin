# 扩展壳：本地可加载，百度桌面网页搜索默认启用高亮与列模式

## What to build

做出可以在 Chrome 里「加载已解压的扩展」打开的 Manifest V3 扩展。打开桌面版百度网页搜索结果页时，按默认偏好工作：列模式为单列居中，高亮开。搜索首页、手机版和垂类结果页不改页面。页面上不放列模式控件。

这一刀先不做弹窗、不做自动翻页取页、不做谷歌。默认偏好写死为单列居中且高亮开即可，后面的弹窗刀会接上可改的偏好。

## Acceptance criteria

- [ ] 构建产物是可本地加载的 Manifest V3 扩展
- [ ] 打开 `www.baidu.com` 的网页搜索结果页后，结果条目按单列居中排列，标题和摘要上有高亮段
- [ ] 高亮段按空格和标点拆分，连续中文不拆，不同段底色不同
- [ ] 搜索框、顶部标签、广告、相关搜索、页码不被搬走，广告和相关搜索上没有高亮
- [ ] 打开百度首页、`m.baidu.com` 或资讯等垂类时，页面不被改动
- [ ] 搜索结果页上没有列模式控件
- [ ] 扩展不请求落地页权限，点进结果后的网站不被高亮
