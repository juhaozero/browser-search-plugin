# 弹窗偏好：列模式、高亮与自动翻页开关，同步后马上生效

## What to build

在扩展图标弹窗里改偏好，不在搜索结果页上放控件。弹窗提供列模式四选一（原始模式、单列、单列居中、双列），以及高亮开关、自动翻页开关。百度和谷歌共用这一套。刚装上时默认是单列居中、高亮开、自动翻页开。不提供页数上限设置。

改完后，已经打开的搜索结果页马上跟着变：换列模式立刻重排（含切回原始模式时还原本页原有结果条目），开关立刻生效。偏好跟着 Chrome 账号同步；同步不可用时退回本机保存，扩展照常能用。

若自动翻页的页面行为尚未接到某个引擎，弹窗仍要能保存并同步该开关；已接通的引擎必须马上遵守。

## Acceptance criteria

- [x] 点击扩展图标打开弹窗，可四选一列模式，并可开关高亮与自动翻页
- [x] 搜索结果页上仍然没有这些控件
- [x] 未改过时，默认是单列居中、高亮开、自动翻页开
- [x] 在弹窗里改列模式后，已打开的百度（以及已接通的谷歌）结果页马上重排，无需刷新
- [x] 关掉高亮后，已有和后续结果条目不再被涂；再打开后马上恢复
- [x] 关掉自动翻页后，滚动不再取下一页；再打开后，滚回底部会继续接页
- [x] 从双列或单列切回原始模式时，本页原有结果条目回到原位，已接上的结果仍留在列表末尾
- [x] 偏好写入可同步存储；同步失败时仍能从本机读回并作用到页面
- [x] 百度和谷歌读到的是同一套偏好
- [x] 弹窗里没有自动翻页页数设置
